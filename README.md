# 跨境电商利润核算器（profit-calculator）

给亚马逊中小卖家的“到手利润”计算器：**售价 − 推荐费 − FBA/仓储 − 采购/头程/关税 − 广告 − 退货 − 汇兑损益 = 真实单件利润**，再按 SKU、按月汇总成利润表。

在线演示：https://laomaiai.github.io/profit-calculator/

英文说明见 [README_EN.md](./README_EN.md)。

## 解决什么问题

亚马逊卖家常只看到销售额，看不到“到手利润”：推荐费、FBA 费每年涨、广告吃掉利润、退货再吃一口、汇率波动又吃一口。Excel 手工表跟不上费率变化，原生工具只给广告端数据，不给“广告后净利润”。

本工具做三件事：

1. **单件利润计算器**：6 层公式逐层展开，每一层都能改；拖动滑杆即时模拟改价、改广告、改退货率后的利润变化；直接给出盈亏平衡价和盈亏平衡 ACOS。
2. **广告与利润联动**：输入月广告花费、广告销售额、总销售额，对照 ACOS、TACoS 与盈亏平衡 ACOS，判断广告后是不是在亏钱。
3. **批量 CSV 导入**：上传自己从 Seller Central 导出的结算/订单 CSV，按 SKU 汇总利润、按月看趋势，亏损 SKU 标红，可导出汇总 CSV。

## 自己的特点

- **公式透明**：每一层成本都列出来，费率来源与核查日期写在页面和 `docs/fees-2026.md` 里，不藏黑箱。
- **本地优先**：纯前端计算，没有后端；你的财务数据不离开浏览器，不上传、不存储。
- **合规边界清晰**：只用你自有导出的 CSV，不爬取亚马逊或任何平台的数据；不涉及股票、加密货币、资金托管或代客交易。
- **汇率有来源**：用 Frankfurter（欧洲央行官方汇率，免费、无 Key、日频），取不到时用标注日期的兜底表，绝不假装实时。

## 3 步本地运行

```bash
npm install
npm run dev      # 打开 http://localhost:5173
npm run build    # 生产构建
npm test         # 单元测试（Vitest）
```

环境要求：Node.js 20+。

## 费率来源与版本

亚马逊 2026 年费率（核查日期 2026-09-10，来源 MyRealProfit / eDesk）：

- 推荐费多数 15%（按类目 8%–15% 可调）
- FBA 配送费 2026-01-15 起平均 +$0.08/件；2026-04-17 起 +3.5% 附加费
- 仓储费淡季 $0.78/立方英尺/月，旺季 $2.40/立方英尺/月

完整口径与版本记录见 [docs/fees-2026.md](./docs/fees-2026.md)。费率每年会变，使用前请在亚马逊官方费率页复核。

## CSV 格式

必填列：SKU、数量、售价；可选列：推荐费、FBA 费、广告花费、退货件数、退货成本、到岸成本、日期。列名接受中英文（见 `src/lib/csv.ts` 的别名表）。示例文件：`public/sample-settlement.csv`（合成数据，仅供演示）。

## 确定性计算层

本工具的所有计算都由代码完成：核心算式在 `src/lib/profit-core.ts`，是纯 TypeScript 确定性函数（无网络请求、无大模型参与），输入相同、输出相同。汇率取数走 Frankfurter API（只传币种代码），取不到时用标注日期的兜底表。本产品不使用任何大模型。

## 测试方法

核心算式全部在 `src/lib/profit-core.ts`（纯 TypeScript 函数，无网络、无 LLM），测试在 `src/lib/profit-core.test.ts`：

```bash
npm test
```

覆盖：推荐费、FBA 附加费、仓储费（淡旺季）、退货成本、ACOS/TACoS、盈亏平衡 ACOS、盈亏平衡价、6 层单件利润公式、汇率换算、按 SKU/按月汇总（含亏损标红与空输入保护）。

## 技术栈

React + Vite + Tailwind CSS + TypeScript；计算层纯 TS 函数；CSV 解析用 papaparse；汇率用 Frankfurter API（浏览器端直接请求，只含币种代码，不含金额）。
