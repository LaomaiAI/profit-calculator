# 费率表 2026（Amazon 美国站）

> 核查日期：2026-09-10
> 来源：MyRealProfit 免费 FBA 计算器（https://myrealprofit.com/amazon-fba-profit-calculator/）、eDesk（https://www.edesk.com/blog/amazon-revenue-calculator/）
> 费率每年会变，使用前请在亚马逊卖家中心官方费率页复核一次。本文件只记录核算时使用的口径，不作为费率承诺。

## 1. 推荐费（Referral Fee）

| 项目 | 口径 |
|---|---|
| 多数类目 | 售价的 **15%** |
| 可调范围 | 按类目 **8%–15%**，本工具默认 15%，可在界面上按实际类目修改 |
| 计算方式 | 推荐费 = 售价 × 费率 |

## 2. FBA 配送费（Fulfillment Fee）

| 项目 | 口径 |
|---|---|
| 2026-01-15 起 | 平均每件 **+$0.08** |
| 2026-04-17 起 | **+3.5%** 燃油/物流附加费（按 FBA 配送费计收） |
| 计算方式 | 含附加费的 FBA 费 = 基准费 × (1 + 0.035) |

基准费本身按商品尺寸与重量分档，卖家应在 Seller Central 的 FBA 费率表里查自己商品的档位，填进工具。

## 3. 仓储费（Storage Fee）

| 季节 | 单价 |
|---|---|
| 淡季（1–9 月） | **$0.78 / 立方英尺 / 月** |
| 旺季（10–12 月） | **$2.40 / 立方英尺 / 月** |

计算方式：仓储费 = 体积（立方英尺）× 存放月数 × 当季单价。
本工具的单件计算器里，仓储费按“分摊到每件的金额”直接输入；批量 CSV 里不含仓储分摊时需另行计入。

## 4. 其他成本（卖家自填，无官方统一价）

| 项目 | 说明 |
|---|---|
| 采购成本 | 出厂价 / 件 |
| 头程物流 | 运到亚马逊仓库的物流费 / 件 |
| 关税 | 按实际税则计 / 件 |
| 广告花费 | 亚马逊站内广告花费，可按 ACOS / TACoS 联动分析 |
| 退货成本 | 退货率 ×（退款管理费 + 退货处理费 + 不可售损失） |
| 汇兑损益 | 售出时汇率与结算时汇率之差；汇率取 Frankfurter（欧洲央行官方汇率）日频价 |
